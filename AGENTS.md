# RO Survivors Drop Wiki

This is an independent, noncommercial, mobile-first static fan reference site. The authoritative requirement is v1.1 in the user's RO assistant docs; do not modify RO assistant or LumiDex. User explicitly authorized public GitHub source and public GitHub Pages on 2026-11-17 for sharing the wiki with friends. Future unrelated production changes still require normal approval.

- Never commit original RO Survivors code/bundles, original game assets, sprites, card images, whole nonofficial wiki dumps, credentials, auth data, tokens or secrets.
- Public images are limited to reviewed GungHo official site artwork: 10 RO Fan Kit monster illustration thumbnails, plus 92 equipment and 66 card icon thumbnails from official RO game-data pages. Their individual sources are documented in `docs/PUBLIC_ASSETS.md`, `public/approved-thumbs/manifest.json` and `public/approved-thumbs/item-card-manifest.json`. The noncommercial fan-site use follows https://ragnarokonline.gungho.jp/support/play-manner/copyright.html ; it does not grant blanket rights to copy RO Survivors / client art. The public website includes the copyright credit.
- The user's original 720 RO Survivors game PNG assets stay exclusively in gitignored `evidence/private-art` and `dist/game-assets` on the Tailscale development machine. Never publish private art, even resized. `VITE_PUBLIC_MODE=1` prevents loading it. Before deploy, always run `node scripts/verify-public-dist.mjs` after a public-mode build; GitHub Actions must check this before Pages upload.
- CI uses GitHub Actions Linux only. No duplicate PR/push checks; the single main push workflow builds, checks and publishes approved static files.
- Data evidence/source verification remains in JSON and docs; never claim unconfirmed probabilities as percentages. Player UI hides raw drop weight.
- Preserve mobile Safari click-first navigation, item/card/stage relationships, source distinctions, Tailscale private preview, and public Pages compatibility.
