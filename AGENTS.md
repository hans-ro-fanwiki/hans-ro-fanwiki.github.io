This is an independent, noncommercial, mobile-first static fan reference site. The authoritative requirement is v1.1 in the user's RO assistant docs; do not modify RO assistant or LumiDex. User explicitly authorized public GitHub source and public GitHub Pages on 2026-11-17 for sharing the wiki with friends. Future unrelated production changes still require normal approval.

Never assume this permission allows high-resolution assets, files for unrelated items, automatic release of newly added art, or monetization.
- The owner's 720 original RO Survivors game PNG assets stay exclusively in gitignored `evidence/private-art` and `dist/game-assets` for the private Tailscale preview; never publish any original PNG or entire spritesheet. - Preserve mobile Safari click-first navigation, item/card/stage relationships, source distinctions, Tailscale private preview, and public Pages compatibility.

See `docs/TWRO_LOCALIZATION.md`. Don't push this Dev revision to `main` or trigger Pages deployment without the user's explicit approval.
