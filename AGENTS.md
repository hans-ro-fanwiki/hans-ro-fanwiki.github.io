# RO Survivors Drop Wiki
This repository is an independent **Dev/Preview-only** static reference project. The authoritative requirement is v1.1 at the user's local RO assistant docs path, not the assistant's codebase. Do not modify RO assistant/LumiDex. Never deploy to production without explicit approval. Do not commit upstream game JS, whole nonofficial wiki dumps, sprites, card images, auth data or secrets. Data are evidence-tagged; unknown drop probabilities cannot be shown as percentages. Asset rights remain unresolved. Never deploy private art; only the owner’s manually prepared gitignored evidence/private-art and dist/game-assets may hold selected PNGs for private Tailscale testing. CI builds do not fetch images. The UI falls back to neutral art if images are unavailable. Preserve mobile Safari click-first navigation and source distinctions.
