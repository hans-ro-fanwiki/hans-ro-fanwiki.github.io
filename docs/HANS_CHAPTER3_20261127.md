# HANS 第三章、卡片、裝備與寵物稽核（2026-11-27）

本次以 HANS V0.16.0 的 [SHA-256 稽核清單](HANS_CHAPTER3_SOURCE.json) 為準。兩份 11/27 主檔、同版 soul 檔及官方素材索引僅留在 Git 忽略的 evidence。以 TypeScript AST 讀取登錄與數值，沒有執行或散布遊戲程式。舊版稽核檔保留給技能、天賦與歷史重建。

- `xe`、`yW`、`RO_C2T` 與 `RO_LAP` 提供第三章資料。三圖六週皆 T8，門檻依序 4500／4950／5400／5900／6450／7000。通過第二章五週目的尼芙菲姆原野後解鎖。經驗試算將三圖波次、怪物及各週目係數納入，與第二章共用新版經驗路徑。
- `Me` 從 202 筆增至 243 筆。對照 11/25 的登錄參數、鑲嵌部位與效果呼叫，36 筆舊卡異動。副本版獨立顯示，獸人英雄同時保留一般版與副本版，因此圖鑑共 244 個顯示形式。
- 卡片 GS 採 `RO_CARDFLOOR`。先算線性 GS 與 `MX` 加值，再與依章節、週目、職業類型計算的 `MG` 模型及 `MV2` 加值比較，最後套首領或副本專屬保底。4144 保留逐週復活與基礎 GS 每週增加 30% 的例外。覆蓋三套權重與既有 41 個職業連結。以遊戲面板或官方即時角色 GS 為實際值。
- `RO_CMB`、`RO_CMECH` 共 33 張特殊能力，每張七組參數。一般版使用未改造至改 5，只有已登錄副本版的卡使用第七組。套裝只要兩張都裝備即可觸發，額外效果按封印卡等級套用。九尾 4490＋4263，夢魘 4485＋4407，焰王 4487＋4430。發現率使用同一個 Discovery 欄位，+3／+5 個百分點只取最高；不直接增加蛋、卡片或裝備掉落發生率。
- `Z`、`re`、`wr` 去重後從 523 增至 727 件。怪物裝備表 `UA` 從 193 增至 242 張，權重保留原始值。章節篩選以已核實的掉落來源為準，實體裝備三章名稱依高裝等、掉落怪物或專屬裝備 ID 判定。副本與世界王命名維持各自優先順序。
- 官方新素材索引涵蓋 204 件新增裝備與 41 張新增卡，並包含三張地圖。以 HEAD 獨立檢查 452 個正式圖檔路徑，全部回傳 HTTP 200、image/png。瀏覽器檢查代表圖檔解碼及錯誤圖示。維基只引用原站連結。
- `RO_C3PL` 寵物改造倍率為 1／1.25／1.5／1.75／2／2.25，與親密度和飾品倍率相乘。高週目蛋可提升現有寵物的改造，進化繼承改造。取樣期間的第二份主檔只改已持有寵物的升級蛋資格判定與依賴檔名。只在候選週目高於現有寵物時例外解鎖，先乘獨立的 10% 資格機率，再進行原本掉落抽選。10% 不是最終掉落率。
