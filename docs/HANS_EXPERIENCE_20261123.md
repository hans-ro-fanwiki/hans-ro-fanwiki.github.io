# HANS V0.15.0 練等經驗試算

以 2026-11-23 的 HANS 公開客戶端取樣。從首頁載入的主檔和對應怪物資料檔均以 SHA-256 鎖定，名稱與雜湊見 `scripts/import-hans-experience.cjs`。匯入器只做 AST 靜態擷取，輸出 16 組關卡波次與 191 隻怪物的等級及經驗值。角色經驗函式只採現行 HANS 邏輯。[HANS 原站](https://ro.hans-webgametw.com/)

## 可核對的機制

| 設定 | 已核對的行為 |
| --- | --- |
| 怪物數量 | 一般波次的每秒生成量、場上存活上限、每次怪物潮的預計怪數都乘上這個設定。地形、仍活著的怪和首領階段會影響實際出怪。 |
| 事件數量 | 菁英的間隔為 45 秒除以倍率，怪物潮為 120 秒除以倍率。菁英替換符合條件的普通刷怪，該隻怪的結算 Base 與 Job 經驗基礎值為 5 倍。 |
| 血量、傷害、速度、刷關等級 | 可能改變擊殺速度及完成率。逐怪結算經驗函式中的直接變數為怪物等級、怪物經驗、菁英、周目與啟用中的全服加成。 |
| 周目 | 第一章一至二周目使用每高一級乘 0.5、最低 1% 的等差規則。第一章三周目起及第二章使用每高一級扣 8 個百分點、最低 15% 的新規則。新規則另套 Base／Job 各自係數，Base Lv70 起採該周目的 Base 獎勵倍率。 |
| 局內經驗寶石 | 寶石推進當局的技能等級。角色結算經驗直接由擊殺累積，由另一套計算處理。 |

## 計算公式與排行榜呈現（2026-11-23 補充）

以下資料源自 SHA 審核的 HANS V0.15.0 客戶端，保留原公式。角色高於怪物的等級差定義為 `D = max(0, Base Lv - 怪物 Lv)`。

- 第一章一、二週目使用舊制：`penalty = max(0.01, 0.5^D)`，Base／Job 乘怪物經驗、關卡週目經驗係數、菁英與全服加成（Job 另乘職業階段和軟上限係數）。
- 第一章三至六週目及第二章全週目使用新制：`penalty = max(0.15, 1 - 0.08 × D)`。
- 新制 Base 逐怪經驗：`原始怪物 EXP × 關卡週目經驗係數 × penalty × 1/3 × (Base Lv >= 70 ? 該週目倍率 : 1) × 菁英倍率 × 全服倍率`。
- 新制 Job 逐怪經驗：`原始怪物 EXP × 關卡週目經驗係數 × penalty × 0.025 × 職業階段修正 × 軟上限修正 × 菁英倍率 × 全服倍率`。
- 第二章的週目倍率從一至六週目為 `1.5／1.75／2／2／2／2`，但 Base Lv 70 前固定使用 `1`；同地圖怪物等級與原始經驗不因週目提高，故未跨 70 的情況下六週目 Base 理論值相同。第一章較高週目會調整怪物等級與關卡經驗係數，因此不能把此結論套用到第一章。
- 每分鐘預估：`模擬總 EXP ÷ ((最後一隻頭目出場秒數 + 結算秒數 + 額外整備秒數) / 60)`。怪物數量影響預計出怪，事件倍率影響菁英及怪物潮的發生間隔。菁英替代普通刷怪，其基礎經驗為五倍。

**排行整合並非竄改經驗**：同一張地圖、同目標（Base 或 Job）的每分鐘計算值完全相同時，清單只顯示 GS 門檻最低的可用週目；展開後仍可看其他符合 GS 與週目條件的結果。不同經驗的週目維持獨立排序。使用者提供「每分鐘擊殺上限」時，只將數值視為所有候選地圖共用的限制，不會憑 GS 推測實際擊殺速度。怪物血量／傷害隨週目上升，若清怪效率下降需用實際結算校準，不能因理論收益相同就認定實際收益一樣。

原站公開活動狀態在查證當下回傳 `xp: null`。試算預設全服加成 1×，可依遊戲畫面調整。[活動狀態](https://ro.hans-webgametw.com/api/raidinfo)

## 可重現的案例

迷宮森林三周目，Base Lv70，Job Lv1／一轉，單刷，無全服加成。模擬每秒按波次的怪物權重結算，角色經驗從當前等級的 0 XP 起算。總長估計 15 分，包含 14 分首領排程、15 秒結算拾取、45 秒供打最後一王及重開。

| 怪物／事件 | 估計全清 Base／分 | 每分鐘最多擊殺 180 隻時的 Base／分 |
| --- | ---: | ---: |
| 1×／1× | 3,799 | 2,274 |
| 2×／1× | 7,408 | 2,393 |
| 1×／2× | 4,426 | 2,346 |
| 2×／2× | 8,588 | 2,410 |

每分鐘擊殺上限是跨波次共用的簡化模型，怪物潮依當時怪池分配，隨後按剩餘時間估計可擊殺數。模型不模擬走位、在場怪物積壓、各怪物同時存活上限、隊友、隨機事件首領、首領召喚或死亡率。結果為可比較的試算，實際結算需再用成對場次核對。

## 實戰核對方式

同一角色、裝備、關卡和周目，用接近的起始 Base 等級與相同全服加成，比較 1×／1×、2×／1× 及 1×／2×。每組記錄至少三場的結算 Base／Job、擊殺數、死亡與實際從開場到下一次開場的耗時。比較包含失敗場次的總經驗除以總時間；若測試期間升等，另記下各場起始等級。

頁面位於「關卡」下的「經驗計算機」。展開「使用教學」可查看欄位和結算讀法。結算「本局」的「怪物」除以「時間（分鐘）」可作為清怪速度估計，例如 8,821 隻、14 分 15 秒，約為每分鐘 619 隻。實戰的每分鐘經驗則以結算經驗除以實際耗時，包含結算與重開。
