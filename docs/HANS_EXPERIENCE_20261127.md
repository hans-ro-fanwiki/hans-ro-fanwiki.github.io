# HANS V0.16.0 經驗計算機實戰校準

2026-11-27 重新由 SHA 固定的 HANS 主檔與怪物檔擷取 16 關、191 怪。來源見 scripts/import-hans-experience.cjs；原始遊戲檔只留本機 evidence。怪物等級、原始 EXP、波次、首領、Job 上限與係數比對未變。

- 逐怪 Base／Job 等差、Lv70 週目分界及菁英 5 倍同舊版，詳細公式見 HANS_EXPERIENCE_20261123.md。新增修正：Job 乘怪物數量倍率的 -0.5 次方（故事關固定 1，此試算為一般遠征）；Base 不乘。Job 還有關卡、職業階段及軟上限修正。
- 怪物潮在可生成位置加入佇列，實際逐批生成；試算每次事件的供給只計一次，以接下來的事件間隔平滑分配，非逐幀模擬。保留普通波次、菁英替換及首領擊殺，提取 maxAlive 供後續研究。未完整模擬地形、怪物積壓、移動、召喚、清王時間及死亡。
- UI 預設 Base Lv60、怪物／事件 2000%、開局經驗進度 0；以單場累計 Base 或 Job 排序，不輸入假設清怪比例、加速、現實耗時或每分鐘擊殺上限。無實測採完整排程的理論擊殺數，並非實際保證。各圖以自身最後首領出場時間及波次累計。
- 實戰校準可輸入完整通關結算的關卡、週目、擊殺、Base、選填 Job；開局等級、倍率、職業階段等沿用上方設定並在套用時凍結。原設定直接重現實測，其他倍率以理論情境相對變化乘實測值。假設同樣相對清怪效率、經驗組成；不套用其他地圖、週目或角色，不代表最優倍率。若實測高於理論供給，也只顯示比率，不稱為實際清怪率。僅頁面暫存，未上傳。
