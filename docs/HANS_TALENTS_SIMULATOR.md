## 重建流程（只在重新審核來源後使用）
1. 首先確認官方頁面、相關 JS 檔案及來源 SHA；官方有更新時先建立新審核快照和相容性測試。
2. `node scripts/extract-hans-talents.cjs --write`：用 TypeScript AST 對固定 SHA 的本機原始快照靜態抽取 **一轉中間檔** `evidence/hans-talents-20261120/first-job-talents.json`；不執行下載的遊戲 JS。
3. `node evidence/hans-talents-20261120/capture-talent-data.mjs`：以隔離的 Chrome 開啟官方公開天賦頁、取得 25 個目前公開可選的職業與渲染後的結構資料，保存為本機忽略的 `official-rendered.json`；不採集登入資料，僅遊戲公開資訊。
4. `node scripts/normalize-hans-talents.mjs`：合併 AST 一轉與獨立天賦頁一二轉快照，再執行 `scripts/extract-hans-third-talents.mjs` 靜態解析固定 SHA 的遊戲本體 `RO_J3`/`tree3`，包含 16 個三轉、三轉節點位置／級數／技能效果靜態摘要；檢查三階總筆數後重建 `public/data/talents.json`。未執行原始遊戲 JS，也沒有收錄原始碼。
5. 重新執行測試、公開版 build、安全檢查與手機／桌面 UI 測試；不得因上游版號異動直接忽略 SHA 審核。

## 模擬器功能
- 第四分頁「天賦」：可選 41 個職業（9 一轉＋16 二轉＋16 三轉）、桌面顯示三棵並排天賦樹、手機預設收合選職業面板並切換三棵樹；三轉顯示中文職業／分支名稱，個別技能保留來源英文原名。
- 採 HANS 官方的分支、節點位置與前置連線，顯示不同階層及已分配點數；點擊圖示加點，說明面板可逐點增減。
- 一轉／二轉各自使用 50 點天賦額度；**三轉使用獨立 70 點**。三轉 12 列，終極天賦第 12 列需先投 55 點。列門檻基數 5，跨列要求及前置滿級需滿足；二轉與三轉均限制單一專精分支，同技能進階路線 A/B 互斥。已實際跑完 48 條三轉分支的合法配點可達性測試。
- 一二轉效果簡述及滿級說明來自獨立天賦頁。三轉由 AST 中已知技能／加成 helper 靜態推導可確認的簡短效果（例如爆擊率、傷害、冷卻、範圍），較複雜的效果只顯示類別或原文路線敘述，不編造精確數字；不宣稱完整角色傷害模擬。
- 版本化分享 URL：`?page=talents&tj=<job>&tb=v1.<sourceCommit>.<base36-ranks>`。原有一轉分享碼保留相同節點序列及版本，可相容還原；非法或不相容來源以錯誤訊息拒絕。
- 2026-11-20 因使用者明確要求實際圖示，**正式版也改為用 HANS HTTPS 原始來源 URL 顯示技能圖示**（代碼只接受英數／底線／連字號；顯示 `/assets/icons/<id>.png`），包括一轉／二轉／三轉 3,168 節點。圖片載入失敗時保留 Lucide fallback；裝備與卡片同樣用 `/assets/items/`、`/assets/cards/`。沒有在 Git、Pages 打包、複製、散布 HANS 原始圖片檔案。引用公開來源不代表取得素材權利人的使用、改作或再散布授權，保留非官方及來源聲明、權利人提出疑慮可下架。
- `scripts/hans-ui-smoke.mjs` 已驗證裝備、卡片、一轉及三轉圖片在隔離 Chrome 中實際載入成功（naturalWidth > 0）、所有遠端圖片請求都位於 HANS 白名單路徑、320–430px 沒有橫向溢出；原站未來更換路徑會退回替代圖示。
- 不需要登入或資料庫，不會改變遊戲角色。

## 驗證與限制
- `npm run typecheck`、`npm test`、`VITE_PUBLIC_MODE=1 npm run build`、`node scripts/verify-public-dist.mjs`。
- `node scripts/hans-ui-smoke.mjs` 在隔離 Chrome 測試配點、分享、重載、重置、二轉頁面及 320／375／390／430px 寬度，不修改使用者既有 Chrome。私人預覽也由隔離瀏覽器測試，完成後關閉。
- 三轉已依 HANS 當前遊戲程式登錄納入，**不代表每個三轉天賦效果都經角色實戰驗證**；獨立展示頁尚未列出三轉。部分天賦名稱仍沿用遊戲程式英文、路線說明未完全在地化，後續可依遊戲內畫面補齊；不同版本可能影響分享碼相容。
- 兩個遊戲內 ID (`kagerou`、`rebellion`) 同時出現在二轉展示頁和三轉遊戲登錄中。維基使用 `kagerou_rank3` 與 `rebellion_rank3` **僅作 UI／分享內部識別**，保留 `sourceJobId`，避免混淆階段；不得把別名當作官方原始 ID。
- 二轉 HANS 明確標示「開發中」，模擬器忠實顯示此狀態；三轉資料的實際解鎖門檻已依程式結構做配點驗證，未掌握玩家實測結果前不把它當作遊戲現況唯一證據。
