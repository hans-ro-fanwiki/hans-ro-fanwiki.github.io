## 使用者截圖的歐西里斯卡片（ID 4144）

HANS 主程式 `RO_LAPC.cardNoScale=[4144]`；用戶端副本／週目卡片實作 `NO=new Set([4144])`，在改卡效果生成和 `RO_CARDFLOOR` 的保底計算都直接令倍率為 **1**。此外，遊戲內圖書館的卡片分數說明也列有「歐西里斯卡片不放大」的例外。

因此，這張卡雖然週目卡片 ID 仍按 `4144 + (lap-1)×1,000,000` 改變，**已核對的 HANS 用戶端公式**對它的效果及 GS 均不放大：一至六週目的用戶端公式都是 **+60 GS**。這項證據必須保留，不把未證實的玩家回報誤稱為官方設定。

**玩家回報後的暫行顯示（待確認）**：使用者希望先照一般卡片週目倍率展示 GS，理由是有人回報改⁴卡 GS 超過 100。網站因此僅對 ID 4144 在 `cardGsContribution` 加單卡覆寫，將官方來源公式一週目 +60 直接乘週目倍率，依序顯示 **60／90／120／150／180／210 GS**（改⁴＝第五週目 +180；改⁵＝第六週目 +210）；此計算**尚無真機面板實測證明**，且與目前用戶端不放大規則不同。**不更動 `cardScore` 原始公式、`cardMultiplier` 或官方卡片效果**，僅調整一般預覽、排行、詳情的共同顯示分數，全部標記「GS 待確認」。若實測證明錯誤，移除 `PROVISIONAL_GS_MULTIPLIER_CARD_IDS` 中的 4144 即可恢復。
