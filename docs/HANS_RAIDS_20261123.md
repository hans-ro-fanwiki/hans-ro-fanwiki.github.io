# HANS V0.15.0 團隊副本

11/23 開放狀態已核對遊戲內公告及原站公開的 `api/raidinfo`。個人門檻、Tier、時限、階段流程與獎勵清單採《遠征副本管理員》實際顯示的遊戲內預覽。八張 minimap 均驗證原站回應 HTTP 200 和 image/png。

- 預覽包含 289 筆裝備池關聯（同一裝備可出現在多關）和 15 張副本卡。卡片依官方預覽對應到該關，倍率 ×4.2。原版卡片的普通地圖來源照舊。
- 20 件裝備為遊戲中從原件註冊的聖誕版本，採 HANS 中文名稱、原件部位／職業限制與基礎數值。副本擲骰的 Tier 和個別物品掉落機率為不同資料，前者按遊戲的關卡預覽顯示，後者未公開。
- 遊戲材料預覽的小數原樣保留。實際勳章數量、兌換價格、每週限額和結算由伺服器決定。精英另計，不將整個預覽池指派給某一隻怪物。
- 原始快照僅放在 Git 忽略的 `evidence/hans-20261123`。檔名與 SHA-256 見 `HANS_RAID_SOURCE_20261123.json`。執行 `node scripts/import-hans-raids.cjs` 可重建公開投影，不執行原站 JS，也不打包素材。

- 副本管理員將硬性補師人數與建議隊伍組成分開顯示。維基沿用這兩個欄位，最低段以 6 人開團顯示。
