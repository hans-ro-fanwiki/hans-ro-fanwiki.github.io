## 急速勘誤及試算工具（2026-11-24）

已核對 V0.15.1 的 `Qy.cd → aa → haste`、`_G.cast → Ks → castHaste` 及 `ut.sc → Ia → mod.per.cd`。其中角色全域急速與單技能局部急速合併到一般冷卻的分母；施法急速獨立計算。舊 catalog 的「冷卻縮減」誤譯不是 GS 或原始數值錯誤。保留官方道具名稱（冷卻藥水／冷卻祝福）、實際冷卻秒數與真正的冷卻時間變化敘述。修正同時套用於匯入器及三轉天賦擷取器，舊的冷卻搜尋仍可查到急速裝備／卡片；不將施法急速混入該篩選。

- 冷卻：base / (1 + max(0, haste + local + buff)/100)，塔倍率、特定 adrenaline、cdExtra 與特殊觸發另計。一般分段急速 Buff 上限 200 點，並非角色急速總上限。
- 施法：base × max(0, 1 − DEX/K) / (1 + max(0, castHaste)/100)，K 單體 100／範圍 150。
- 全域範圍或近戰距離：x = 1 + 原始加成/100，x>1 時 S(x)=1+(x−1)/(1+(x−1)/2)，兩個全域欄位獨立套用，不能解讀為所有技能最終範圍上限三倍。
- 一般承傷：先扣護甲，再乘角色減傷（最多60%）與一般暫時減傷合計的剩餘比例（通常合計75%上限），再乘 1−DEF/(DEF+80)，四捨五入最低1。負重 brace、免疫、閃避、護盾、固定比例扣血等特例不納入。
- 技能下拉帶入圖鑑所記錄的基礎冷卻；特殊計時、層級變動、模式倍率需另外核實。公式試算不等同遊戲內實測，不從玩家回報推測合法配裝最大值或 DPS。
