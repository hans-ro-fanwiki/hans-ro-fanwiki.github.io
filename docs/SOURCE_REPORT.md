### 欄位差異與保留疑點

- **飾品 slot：** 原站與候選皆見 `acc`；不可把 `accessory` 當作資料值。
- **法師可裝限制：** 候選資料的 `jobs` 陣列可用於初步列表，需再核對作者遊戲的共通裝備、進階職業映射及特殊武器／性別限制。**不能當作完成權威核准。**
- **卡片效果：** 候選列出 4010、4023、4077、4100、4330 五張包含冷卻字句的卡片。原站的卡面圖片 ID 能對應，不表示「效果」或「掉落怪物」已核實。中文原始字句被當成候選展示。
- **關卡開放：** 候選標示 8 開放、2 未開放；已核對原站存在多個關卡配置，但並未把「程式存在」當成「目前對玩家開放」。限時活動另標注。
- **掉落率：** `rate` 可能是權重而非實際單場百分比；絕不依數值推算%。
- **活動／劇情／起始／獎勵** 與 `monsterDrop` 拆分。活動和劇情取得不列為一般關卡怪物掉落。
- **怪物 ID 出現於程式**、**圖片 ID 有命中** 都不代表關係或掉落成立。來源狀態逐筆設定。
